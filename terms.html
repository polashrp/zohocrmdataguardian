2. Description of Service

Data Guardian is a Zoho CRM Sigma Extension that provides automated data quality management, including but not limited to:

  • Health score calculation for CRM records
  • Email address validation via third-party API
  • Address verification via third-party API
  • Phone number format validation
  • Business registration number validation
  • Automated task creation and management
  • Weekly and monthly report generation

The Extension operates within your Zoho CRM instance and accesses data as described in our Privacy Policy.
